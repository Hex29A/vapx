vapx

Manage Axis network cameras from the command line: firmware, users, ACAP, network, batch jobs across many cameras. One static binary, no runtime.

curl -fsSL https://vapx.29a.se/install | sh

Verifies the SHA-256 checksum and installs to your home directory, no sudo. Run it again to update. Read the script first.
